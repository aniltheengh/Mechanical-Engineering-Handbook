## Source-quality rules

- **Primary normative**: licensed governing code / approved owner specification actually consulted for the project.
- **Authoritative informative**: standards publisher catalogue, industry association technical guidance, regulator engineering documents.
- **Manufacturer-specific**: actual model-specific instructions and curves govern relevant installation choices.
- **Analytical**: derived equation under explicit assumptions; independently tested with reproducible code where feasible.
- **Unverified**: fact or claim still requiring an authoritative primary source; cannot be used as acceptance basis.

Sources are referenced by key per entry, but most entries describe general principles. A source anchor does **not** imply every sentence is directly quoted or endorsed by that source.
