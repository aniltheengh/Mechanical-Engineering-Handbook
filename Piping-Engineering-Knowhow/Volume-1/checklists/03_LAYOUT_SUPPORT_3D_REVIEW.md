# 03 — Routing / 3D / support review

- [ ] P&ID connectivity, tags, flow arrows, orientation, valves and line spec match model.
- [ ] High-point venting and low-point drainability checked by actual elevations.
- [ ] Valve operation, actuator travel, maintenance removal and access paths reserved.
- [ ] Thermal movements, equipment nozzle loads, pipe restraint types and anchor loads reviewed.
- [ ] Support loads evaluated for operating, empty, maintenance and hydrotest states.
- [ ] Weld/fit-up clearances, spool split, lifting route and field tie-ins checked.
- [ ] Flanges/bolts/gaskets and component material/ratings match the line class.
- [ ] Clashes checked beyond static geometry, including insulation and movement.
