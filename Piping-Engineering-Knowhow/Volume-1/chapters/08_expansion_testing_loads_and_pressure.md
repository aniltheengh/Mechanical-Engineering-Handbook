# Chapter 08 — Expansion, testing loads and pressure

> Scope: general educational engineering baseline, **not** a project-accepted design or substitute for the governing code and manufacturer documents.

<a id="pk-0029"></a>

## PK-0029 — Bellows create pressure thrust

**Engineering mechanism.** Unrestrained expansion joints can transfer large pressure thrust loads to anchors despite absorbing movement.

**Decision procedure.** Use only the appropriate restrained/unrestrained joint design and manufacturer-specified anchor/guide layout.

**Verification / closeout.** Calculate pressure thrust and analyze joint movement limits, fatigue and installation offsets.

**Failure mode or limitation.** Putting a bellows in a long straight run without structural design can be dangerous.

**Reference anchors.** [EXP](../reference/SOURCES.md#exp).

**Entry state:** `BASELINE-RESEARCHED`; **project acceptance:** `NOT ASSESSED`.

## PK-0030 — Hydrotest changes support loading

**Engineering mechanism.** A line filled with test water can weigh far more than an empty gas service line; temporary load paths may govern supports.

**Decision procedure.** Define test medium and temporary support plan before construction.

**Verification / closeout.** Check support capacity, allowable deflection, venting, drains and equipment isolation under test conditions.

**Failure mode or limitation.** Designing supports only for normal service can overlook test-load failure.

**Reference anchors.** [B31.3](../reference/SOURCES.md#b313), [EXP](../reference/SOURCES.md#exp).

**Entry state:** `BASELINE-RESEARCHED`; **project acceptance:** `NOT ASSESSED`.

## PK-0031 — Pipe wall sizing is not just pressure

**Engineering mechanism.** Wall thickness selection depends on governing code formula, material allowable stress, corrosion/erosion allowance, tolerance, external pressure, loads and joining details.

**Decision procedure.** Treat pressure thickness as one check within an approved line class rather than an isolated universal formula.

**Verification / closeout.** Verify code edition, material grade, design temperature, corrosion allowance and purchase tolerance.

**Failure mode or limitation.** Using textbook thin-wall equations alone to sign off a piping system is not sufficient.

**Reference anchors.** [B31.3](../reference/SOURCES.md#b313), [B36.10](../reference/SOURCES.md#b3610).

**Entry state:** `BASELINE-RESEARCHED`; **project acceptance:** `NOT ASSESSED`.

## PK-0032 — Flexibility matters more than minimum length

**Engineering mechanism.** Long straight pipe between rigid connections can generate excessive expansion reactions; offsets may supply flexibility.

**Decision procedure.** Evaluate displacement stress, equipment movement and sustained/occasional load cases per governing code.

**Verification / closeout.** Analyze high-temperature or unusually constrained systems with approved stress methods.

**Failure mode or limitation.** Extra elbows introduce hydraulic loss but can be structurally beneficial; optimize both disciplines.

**Reference anchors.** [EXP](../reference/SOURCES.md#exp), [B31.3](../reference/SOURCES.md#b313).

**Entry state:** `BASELINE-RESEARCHED`; **project acceptance:** `NOT ASSESSED`.
