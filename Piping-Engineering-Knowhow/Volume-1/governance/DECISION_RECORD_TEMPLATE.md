# Engineering decision record — copy one per actual decision

- Record ID / issue / date / owner:
- P&ID, line number(s), equipment tags and document revisions:
- Applicable jurisdiction / code / edition / owner spec:
- Physical system boundary and service fluid:
- Design/normal/min/max pressure and temperature (absolute/gauge specified):
- Flow ranges / density / viscosity / vapor pressure:
- Line material, dimensions, roughness, fittings and component data:
- Considered operating states (normal/startup/shutdown/upset/test/maintenance):
- Explicit assumptions and source of each assumption:
- Alternative configurations and rejected options:
- Governing equations and independently checked calculations:
- Manufacturer datasheet reference and allowed loads/limits:
- Uncertainties and sensitivity checks:
- Verification evidence (calc log / drawing / test / inspection / review):
- Safety implications and hazard-review linkage:
- Decision and acceptance criteria:
- Decision state (proposed / reviewed / accepted / superseded):
- Reviewer and approval authority:
- Reopen triggers (new evidence, changed operating basis/code/OEM data/errors):

**Rule:** do not mark accepted without a real project authority and referenced evidence.
